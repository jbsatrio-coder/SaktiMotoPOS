# SAKTI MOTO POS

## Project Overview

SAKTI MOTO POS adalah aplikasi manajemen bengkel motor berbasis Google Spreadsheet dan Google Apps Script.

Project ini dikembangkan untuk memenuhi kebutuhan operasional bengkel skala kecil hingga menengah dengan fokus pada kecepatan transaksi, kemudahan penggunaan, dan kemudahan pengembangan di masa depan.

---

# Product Vision

Menjadi sistem operasional bengkel motor yang sederhana, cepat, stabil, dan mudah dikembangkan.
